# Programming Paradigms Laboratory

In Task 1, I used a for loop and conditional statements to group events by time of day, skipping invalid hours.

In Task 2, I used a pure function together with filter and map to process the same events without loops.

In Task 3, I wrote a reusable group_by function that accepts different callbacks, allowing the same function to group events in different ways.

I noticed that imperative programming is easier to follow step by step, while functional programming focuses more on transforming data using functions.
